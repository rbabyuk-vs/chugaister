# ESP32 + SN74AHCT125D + WS2812B 5×5

## 1. Як зараз підключено

На цьому етапі ESP32 живиться **тільки від USB комп'ютера**.

Зовнішній 5 V блок живлення живить:
- `SN74AHCT125D`
- матрицю `WS2812B 5×5`

Усі `GND` мають бути спільними.

```text
MacBook / USB
     │
     ▼
   ESP32
     │
     │ GPIO18
     ▼
SN74AHCT125D
     │
     │ DATA
     ▼
 WS2812B 5×5


Зовнішній БЖ 5 V
     ├──────────────→ SN74AHCT125D VCC
     └──────────────→ WS2812B VCC

Зовнішній БЖ GND
     ├──────────────→ SN74AHCT125D GND
     ├──────────────→ WS2812B GND
     └──────────────→ ESP32 GND
```

### Перший канал SN74AHCT125D

```text
ESP32 GPIO18
     │
     ▼
pin 2 — 1A
SN74AHCT125D
pin 3 — 1Y
     │
     ▼
WS2812B DIN
```

`pin 1 (1OE)` має бути підключений до `GND`, щоб перший буфер був увімкнений.

ESP32 під час прошивки та тестування живиться **тільки від USB**.

# 3. Конденсатори

## 100 nF біля SN74AHCT125D

Керамічний конденсатор `100 nF` ставиться між:

```text
pin 14 VCC (+5 V)
        │
      100 nF
        │
pin 7 GND
```

Полярності немає.

Ставити якомога ближче до ніжок `14` і `7`.

---

## 470–1000 µF біля WS2812B

Електролітичний конденсатор ставиться паралельно живленню матриці:

```text
WS2812B VCC (+5 V)
        │
       (+)
     1000 µF
       (-)
        │
WS2812B GND
```

Полярність важлива:

- `+` → `+5 V`
- `-` → `GND`

---

# 4. Розпіновка SN74AHCT125D

Вид **зверху на мікросхему**.

Крапка або виріз позначає сторону `pin 1`.

```text
              ┌─────────────┐
      1OE   1 │●           │ 14  VCC
       1A   2 │            │ 13  4OE
       1Y   3 │            │ 12  4A
      2OE   4 │            │ 11  4Y
       2A   5 │            │ 10  3OE
       2Y   6 │            │  9  3A
      GND   7 │            │  8  3Y
              └─────────────┘
```

## Використовуємо тільки перший буфер

| Pin | Назва | Підключення |
|---:|---|---|
| 14 | `VCC` | `+5 V` |
| 7 | `GND` | спільний `GND` |
| 1 | `1OE` | `GND` |
| 2 | `1A` | `ESP32 GPIO18` |
| 3 | `1Y` | через `330–470 Ω` до `WS2812B DIN` |

### Невикористані канали

Для фінальної схеми бажано вимкнути невикористані буфери:

```text
pin 4  (2OE) → +5 V
pin 10 (3OE) → +5 V
pin 13 (4OE) → +5 V
```

Їхні `A` та `Y` можна не використовувати.

---

# 5. WS2812B 5×5

На матриці є:

```text
GND
VCC
DIN
GND
```

з боку входу даних та:

```text
GND
VCC
DOUT
GND
```

з іншого боку.

Для одного модуля використовуємо:

```text
VCC  → +5 V
GND  → GND
DIN  → DATA від SN74AHCT125D
```

`DOUT` не підключаємо.

Він потрібен тільки для наступної матриці:

```text
матриця 1 DOUT → матриця 2 DIN
```


# 7. Мінімальний тестовий код

```cpp
#include <FastLED.h>

#define LED_PIN 18
#define NUM_LEDS 25

CRGB leds[NUM_LEDS];

void setup() {
  Serial.begin(115200);
  delay(1000);

  Serial.println("BOOT");

  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);

  FastLED.clear();
  FastLED.show();

  delay(500);

  FastLED.setBrightness(40);
  fill_solid(leds, NUM_LEDS, CRGB::Red);
  FastLED.show();

  Serial.println("DONE");
}

void loop() {
  delay(1000);
  Serial.println("alive");
}
```

# 8. Якщо LED блимають випадковими яскравими кольорами

Перевірити в такому порядку:

1. `100 nF` між `pin 14` і `pin 7` SN74AHCT125D.
2. `330–470 Ω` між `pin 3 (1Y)` і `DIN`.
3. Спільний `GND` між ESP32, БЖ, SN74AHCT125D і WS2812B.
4. Короткий DATA-провід.
5. `1000 µF` між `VCC` і `GND` біля матриці.
6. `pin 1 (1OE)` точно на `GND`.
7. Матриця підключена саме через `DIN`, а не `DOUT`.
